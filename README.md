## Проект Скайр (Skyr): Моностатический измеритель ВНГО (CloudCam)

Аппаратно-программный комплекс для пассивного оптического измерения высоты нижней границы облачности (ВНГО), а также скорости и направления ее движения. 

## Теоретическая база
Проект использует моностатический метод С.В.Зуева. В отличие от стереоскопии (триангуляции), требующей точного разнесения камер на большую базу, данный метод использует две камеры, расположенные вплотную, но оснащенные объективами с **разными фокусными расстояниями** (например, 12 мм и 16 мм). 

Расстояние до облака $a$ вычисляется по законам геометрической оптики на основе коэффициента подобия изображений $K_y$

$a = f'_1 \cdot \frac{K_y - 1}{K_y - K_f}$

где:
* $f'_1$ — фокусное расстояние первого объектива;
* $K_y$ — вычисленный коэффициент подобия изображений;
* $K_f$ — отношение фокусных расстояний двух объективов ($f_1 / f_2$).

Для определения ВНГО с учетом кривизны Земли применяется формула с использованием зенитного угла. Определение скорости и направления движения облачности происходит путем анализа видимого смещения фрагментов на кадрах, сделанных с интервалом (например, 6 секунд) с вычислением матрицы гомографии.

## Требования к оборудованию
1.  Вычислительный модуль: Raspberry Pi (рекомендуется 4B или выше).
2.  Камеры: 2x USB или CSI камеры с фиксированными объективами разного фокусного расстояния (отсутствие автофокуса критически важно).
3.  Калибровочный шаблон (шахматная доска) для устранения радиальной дисторсии.

## Программный стек
* ОС: Raspberry Pi OS (Debian)
* Язык: Python 3.x
* Компьютерное зрение: OpenCV (детекторы Харриса, алгоритм RANSAC).
* Веб-интерфейс: Flask/FastAPI (для отображения расчетов ВНГО).

## Инструкция по развертыванию (Deployment Guide)

### Шаг 1. Подготовка ОС и зависимостей
Обновите пакеты Raspberry Pi и установите системные библиотеки, необходимые для сборки OpenCV:
```bash
sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install build-essential cmake pkg-config -y
sudo apt-get install libjpeg-dev libtiff5-dev libjasper-dev libpng-dev -y
sudo apt-get install libavcodec-dev libavformat-dev libswscale-dev libv4l-dev -y
sudo apt-get install libxvidcore-dev libx264-dev -y
sudo apt-get install libatlas-base-dev gfortran -y
```

### Шаг 2. Клонирование репозитория и виртуальная среда
Склонируйте репозиторий проекта и создайте изолированную среду:
```bash
git clone https://github.com/your-username/skyr-cloudcam.git
cd skyr-cloudcam/raspberry/opt/cloudcam/
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r server/requirements.txt
```

### Шаг 3. Жесткая калибровка камер (Критический этап)
Без коррекции радиальной дисторсии и смещения оптических осей вычисление $K_y$ выдаст существенную ошибку.
1.  Распечатайте PDF с шахматной доской (`processing/calib/chessboard/9x6.pdf`) и закрепите на плоской жесткой поверхности.
2.  Запустите скрипт сбора калибровочных пар:
    ```bash
    python processing/calib/capture_calib_pairs.py
    ```
    Сделайте не менее 20 снимков с разных ракурсов, перекрывающих всю площадь кадра.
3.  Выполните расчет внутренних параметров (intrinsic parameters) для каждой камеры:
    ```bash
    python processing/calib/calibrate_fisheye_single.py
    ```
    *Результат калибровки будет сохранен в `processing/config.json`.*

### Шаг 4. Настройка констант
Отредактируйте файл `processing/config.json`. Внесите физические константы:
* Точные фокусные расстояния объективов.
* Зенитный угол установки камер (если они направлены не строго вертикально).

### Шаг 5. Запуск сервиса
Для ручной проверки скрипта расчета ВНГО:
```bash
python processing/cbh_compute.py
```
*(При возникновении `UnicodeEncodeError` убедитесь, что локаль консоли выставлена в UTF-8: `export LC_ALL=C.UTF-8`)*

Для запуска в качестве демона через systemd:
```bash
sudo cp server/cloudcam.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable cloudcam.service
sudo systemctl start cloudcam.service
```
После этого веб-интерфейс будет доступен на порту, указанном в конфигурации сервера.
