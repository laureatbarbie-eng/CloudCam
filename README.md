## 📖 Описание проекта

**Подмодуль определения высоты нижней границы облачности, скорости и направления ветра в слое 300-1500 м по данным программы по идентификации и классификации форм облачности** — это проект, который позволяет автоматически захватывать фотографии с помощью двух камер ESP32-CAM с разным фокусным расстоянием (12 мм и 16 мм) и загружать их на удаленный сервер (Raspberry Pi 5). Устройство работает автономно от PowerBank, делая снимки по расписанию каждые 10 минут, затем переходит в режим глубокого сна для экономии энергии. После пробуждения устройство подключается к Wi-Fi, синхронизируется со второй камерой, делает снимок и отправляет его на сервер Pi.

### 🎯 Основные возможности

- 📷 Автоматическое фотографирование с ESP32-CAM (OV2640)
- 📤 Загрузка фотографий на HTTP-сервер методом POST
- ⏰ Автоматическая съемка по расписанию (по умолчанию каждые 10 минут)
- 😴 Режим глубокого сна между съемками для экономии энергии
- 🌐 Подключение к Wi-Fi для передачи данных
- 🎨 Настройка параметров камеры (качество, формат, баланс белого)
- 🔄 Автоматическая повторная попытка при неудачной загрузке
- 📶 Индикация состояния с помощью светодиодов

### 🛠️ Технические характеристики

- ✅ Микроконтроллер: ESP32 (на плате ESP32-CAM)
- ✅ Камера: OV2640 (до разрешения UXGA 1600×1200 )
- ✅ Память: PSRAM (необходима для работы камеры)
- ✅ Интерфейс: UART, Wi-Fi
- ✅ Питание: 5V USB внешний источник
- ✅ Потребление: минимальное в режиме сна (~10μA)
